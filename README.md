# BY Финансы - Финансовый менеджер 🇧🇾

Финансовый менеджер для учёта личных финансов с поддержкой белорусского рубля (BYN) и доллара США (USD) по курсу Национального Банка Республики Беларусь (НБРБ).

## Возможности

### 💰 Учёт финансов
- **Приход / Расход / Остаток** - полный учёт в BYN
- **Автоматический пересчёт в USD** по курсу НБРБ на день операции
- Формула: `USD = BYN / курс_НБРБ`
- Курс фиксируется на момент создания операции и сохраняется

### 💵 Курс НБРБ
- Автоматическая загрузка курса с официального API: `https://api.nbrb.by/exrates/rates/USD?ondate=YYYY-MM-DD&parammode=2`
- Кэширование курсов для оффлайн работы
- Возможность ручного редактирования курса
- Отображение текущего курса на главном экране: `1 USD = X.XXXX BYN`

### 🏷️ Источники доходов и расходов
- **Доходы**: Зарплата, Фриланс, Бизнес, Инвестиции, Подарки, Прочие
- **Расходы**: Продукты, Транспорт, Жильё, Здоровье, Развлечения, Одежда, Кафе, Связь, Образование, Прочие
- Создание своих категорий с эмодзи-иконками
- Редактирование и удаление
- Цветовая дифференциация

### 📊 Статистика
- Общий баланс в BYN и USD
- Сумма доходов и расходов отдельно
- Фильтрация по периоду: Сегодня, Неделя, Месяц, Год, Всё время
- Фильтрация по типу: Доходы / Расходы
- Последние операции на главном экране
- История всех операций

### 📱 Технические особенности
- **Android**: 7.0+ (API 24+)
- **База данных**: Room (локальное хранение)
- **UI**: Jetpack Compose + Material 3
- **Сеть**: Retrofit + OkHttp для NBRB API
- **Оффлайн**: Полная работа без интернета, курс берётся из кэша

## Сборка APK через GitHub Actions

Проект настроен для автоматической сборки APK средствами GitHub Actions.

### Как собрать:

1. **Автоматически при пуше**:
   - Любой пуш в ветки `main` или `arena/**` запускает сборку
   - APK появляется в разделе **Actions** → последний workflow → **Artifacts**

2. **Вручную**:
   - Перейдите в **Actions** → **Build APK - BY Finance Manager** → **Run workflow**
   - После завершения скачайте APK из Artifacts

3. **Релиз**:
   - При ручном запуске или пуше в main создаётся GitHub Release с APK файлами
   - Файлы: `BY-Finance-Manager-v1.0-debug.apk` и `BY-Finance-Manager-v1.0-release.apk`

### Локальная сборка (если есть Android SDK):

```bash
./gradlew assembleDebug
# APK будет в app/build/outputs/apk/debug/app-debug.apk
```

## Использование

1. **Добавьте источники**: Перейдите в "Источники" → создайте свои категории
2. **Добавьте операцию**: Нажмите + → выберите тип (доход/расход) → введите сумму в BYN → выберите дату (курс НБРБ подтянется автоматически) → выберите источник → сохраните
3. **Смотрите баланс**: На главной - общий баланс, доходы, расходы в BYN и USD
4. **Фильтруйте**: В "Операции" - фильтр по периоду и типу

## API НБРБ

Используется официальный API Национального Банка РБ:

- Текущий курс: `https://api.nbrb.by/exrates/rates/USD?parammode=2`
- Курс на дату: `https://api.nbrb.by/exrates/rates/USD?ondate=2023-06-15&parammode=2`
- По ID валюты (431 = USD): `https://api.nbrb.by/exrates/rates/431?ondate=2023-06-15&parammode=2`

Ответ:
```json
{
  "Cur_ID": 431,
  "Date": "2023-06-15T00:00:00",
  "Cur_Abbreviation": "USD",
  "Cur_Scale": 1,
  "Cur_Name": "Доллар США",
  "Cur_OfficialRate": 3.1234
}
```
